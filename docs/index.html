What is LOX?

LOX is an IoT-enabled smart locker ecosystem. Users can reserve and unlock lockers through a mobile application, while administrators can monitor and manage lockers through a connected system.

Secure

Provides safe temporary storage with electronic locking and authentication.

Smart

Uses sensors, ESP32 control and software logic to automate locker access.

Connected

Connects the mobile app, backend and hardware locker system together.

Why LOX is Needed

No Secure Storage

Many public places do not provide safe temporary storage.

Risk of Theft

Students and passengers may lose personal belongings.

Manual Management

Traditional lockers need keys and manual supervision.

Poor Convenience

Users need a faster and easier way to access lockers.

Our Solution

LOX allows users to reserve lockers, unlock them remotely, monitor locker status and securely store items using a mobile app and IoT-enabled locker hardware.

  • Mobile app reservation
  • Remote locker control
  • Real-time locker status
  • Automatic locking
  • Secure authentication

Hardware Components

ESP32

Controls sensors, locks and communication.

OLED Display

To Show the Locker Status.

Vibration Sensor

To detect any unauthorized access or tampering.

Magnetic Door Sensor

To check whether the door is open or closed.

Solenoid Lock

Locks and unlocks the locker door.

LED Indicators

Shows free, reserved or locked status.

Buzzer Alarm

Provides audible alerts for security events.

Relay Module

ToEnsures stable and continuous power for all locker components, maintaining reliable operation.

Buck Converter

To reduce the power supply voltage to the required level.

12V Power Pack

Provides power to the complete system.

Lithium Ion Battery

Provides backup power for the system.
